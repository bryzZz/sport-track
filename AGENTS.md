## Общее описание

MVP проект для отслеживания прогресса в спортзале

1. Можно создать шаблон тренировки
2. Тренировка состоит из:
   - Выбор упражнения из списка
   - Выбор количества подходов, повторений и веса
   - Можно оставить комментарий
3. Можно выбрать тренировку для того чтобы отметить как были выполнены упражнения
   - Можно отметить каждый подход отдельно, какой был вес и количество повторений
   - Видно план
4. После отметки упражнений можно завершить тренировку кнопкой
5. Можно посмотреть статистику по выполнениям тренировки (в виде квадратиков как в github, зеленый - тренировка была сделана, прозрачный - нет)
6. Можно посмотреть статистику по одному конкретному упражнению в конкретной тренировке (как изменились подходы, повторения и веса)

### Code Implementation Guidelines

Следуй этим правилам при написании кода:

- Используй ранние возвраты (early return) везде, где это возможно, для повышения читаемости кода.
- Используй описательные имена переменных и функций/const. Обработчики событий должны иметь префикс `handle`, например `handleClick` для `onClick` и `handleKeyDown` для `onKeyDown`.
- Используй `const` вместо объявлений функций, например: `const toggle = () => {}`. По возможности определяй типы.
- Используй `useMemo`, `useCallback` и `useEffect` по минимуму.
- Если стиль можно сделать через tailwind делай через него, во вторую очередь inline стили
